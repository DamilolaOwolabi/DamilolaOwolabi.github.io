## Overview

An interactive dashboard of the Pokémon dataset, built in a Jupyter notebook with **Plotly** and exported to a single HTML page. It combines five views of the data:

- Height vs. weight, colored by primary type
- Number of Pokémon per generation
- Share of Pokémon by primary type
- Average HP, attack and defense by generation
- Distribution of base experience points

Dropdown filters narrow every chart to a generation or a primary type.

## Design choices

- **One question per chart.** Each panel answers a single question, so the dashboard reads at a glance.
- **Clear labeling.** Every panel has its own title, and axes and legends are labeled.
- **Interactivity where it helps.** Hover for exact values; filter instead of adding more charts.
