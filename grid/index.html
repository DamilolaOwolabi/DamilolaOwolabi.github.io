How this works

Days through the end of ERCOT's latest monthly release come from ERCOT's Fuel Mix Report (15-minute settlement data). More recent days come from ERCOT's public fuel mix dashboard (5-minute data). When the report catches up, it replaces the dashboard numbers for those days.

Shares exclude energy storage, which both charges and discharges, so the mix reflects generating sources. "Other" covers biomass and remaining sources; the dashboard reports less detail for it than the settlement report. Peaks are the highest 15-minute (report) or 5-minute (dashboard) total.

A Python job I wrote (source) runs every morning on GitHub Actions, updates the data, and republishes this page.
